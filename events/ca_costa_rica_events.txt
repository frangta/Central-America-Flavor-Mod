# FASE 2: Diario "La Pacificacion del Norte" (mayo - agosto 1836)
# Rediseno CAFM segun Fernandez Guardia, "La guerra de la Liga y la
# invasion de Quijano", Revista del Archivo Nacional 3 (1939).
#
# Todos los eventos de esta fase los dispara el diario je_ca_pacificacion_norte
# (on_weekly_pulse -> ca_cos_pacificacion_beats_effect), uno por semana y en
# orden historico. Ninguno va en on_actions.
#
#   .40  May 1836   El comisionado insultado (Joaquin Rivas en la villa de Nicaragua)
#   .41  27 jun     Los ligueros vuelven a la bandera (facultades extraordinarias)
#   .4   29 jun     El motin de la Villa
#   .5   29-30 jun  Juan Rafael Munoz se proclama jefe politico
#   .6   7 jul      El saqueo de Bagaces
#   .61  8 jul      El segundo asalto
#   .7   jul        El desembarco en El Bolson (requiere progreso >= 40)
#   .71  24 jul     Sapoa (requiere la expedicion en campana)
#   .8   4 ago      La oferta de Morazan (evento de la UCA) -> .81 La respuesta
#
# Progreso historico aproximado: 5+25+15+15+10+10+10 = 90, mas el avance
# semanal (+1 con la expedicion en campana, +3 con Quijano expulsado).
# El diario se completa hacia mediados de agosto de 1836.
# =========================================================================

# Evento 40: El comisionado insultado (mayo de 1836)
ca_costa_rica_events.40 = {
    type = country_event
    placement = root

    title = ca_costa_rica_events.40.t
    desc = ca_costa_rica_events.40.d
    flavor = ca_costa_rica_events.40.f

    icon = "gfx/interface/icons/event_icons/event_diplomacy.dds"
    on_created_soundeffect = "event:/SFX/UI/Alerts/event_appear"

    duration = 3

    trigger = {
        always = no # Lo dispara je_ca_pacificacion_norte
    }

    immediate = {
        set_variable = ca_cos_pn_comisionado_fired
    }

    # Historica: protesta diplomatica ante Zepeda
    option = {
        name = ca_costa_rica_events.40.a
        default_option = yes
        add_modifier = { name = ca_cos_prestige_loss_small months = 12 }
        c:NIC ?= { change_relations = { country = ROOT value = -10 } }
        change_variable = { name = ca_pacificacion_progress add = 5 }
        ai_chance = { base = 70 }
    }

    # Reforzar la frontera: el motin sera menos destructivo
    option = {
        name = ca_costa_rica_events.40.b
        add_treasury = -2000
        set_variable = ca_cos_frontera_reforzada
        c:NIC ?= { change_relations = { country = ROOT value = -20 } }
        change_variable = { name = ca_pacificacion_progress add = 10 }
        ai_chance = { base = 20 }
    }

    # Pedir a la Federacion que llame al orden a Nicaragua
    option = {
        name = ca_costa_rica_events.40.c
        trigger = { exists = c:UCA }
        c:UCA ?= { change_relations = { country = ROOT value = 10 } }
        change_variable = { name = ca_pacificacion_progress add = 5 }
        ai_chance = { base = 10 }
    }
}

# Evento 41: Los ligueros vuelven a la bandera (27 de junio - 4 de julio de 1836)
ca_costa_rica_events.41 = {
    type = country_event
    placement = root

    title = ca_costa_rica_events.41.t
    desc = ca_costa_rica_events.41.d
    flavor = ca_costa_rica_events.41.f

    icon = "gfx/interface/icons/event_icons/event_military.dds"
    on_created_soundeffect = "event:/SFX/UI/Alerts/event_appear"

    duration = 3

    trigger = {
        always = no # Lo dispara je_ca_pacificacion_norte
    }

    immediate = {
        set_variable = ca_cos_pn_ligueros_fired
    }

    # Historica: facultades extraordinarias, 800 hombres con Villasenor,
    # donativo de Ulloa (1,500 pesos) e indulto del 4 de julio
    option = {
        name = ca_costa_rica_events.41.a
        default_option = yes
        add_treasury = -3500
        set_variable = ca_cos_expedicion_en_campo
        set_variable = ca_cos_ligueros_indultados
        if = {
            limit = { NOT = { has_global_variable = cafm_hc_villasenor } }
            cafm_spawn_or_transfer = { KEY = villasenor TEMPLATE = cafm_vicente_villasenor RULER = no }
        }
        add_loyalists = { value = 0.05 culture = cu:costa_rican }
        ca_cos_change_soberania_effect = { VALUE = 5 }
        change_variable = { name = ca_pacificacion_progress add = 25 }
        ai_chance = { base = 70 }
    }

    # La expedicion sale, pero sin perdon para la Liga
    option = {
        name = ca_costa_rica_events.41.b
        add_treasury = -5000
        set_variable = ca_cos_expedicion_en_campo
        add_radicals = { value = 0.03 culture = cu:costa_rican }
        change_variable = { name = ca_pacificacion_progress add = 15 }
        ai_chance = { base = 25 }
    }

    # Esperar noticias mas claras: no sale ninguna expedicion
    option = {
        name = ca_costa_rica_events.41.c
        ai_chance = { base = 5 }
    }
}

# Evento 4: El motin de la Villa (29 de junio de 1836)
ca_costa_rica_events.4 = {
    type = country_event
    placement = root

    title = ca_costa_rica_events.4.t
    desc = ca_costa_rica_events.4.d
    flavor = ca_costa_rica_events.4.f

    icon = "gfx/interface/icons/event_icons/event_fire.dds"
    on_created_soundeffect = "event:/SFX/UI/Alerts/event_appear"

    duration = 3

    trigger = {
        always = no # Lo dispara je_ca_pacificacion_norte
    }

    immediate = {
        set_variable = ca_motin_villa_fired
        set_variable = ca_crisis_guanacaste_active
        if = {
            limit = { NOT = { has_variable = ca_pacificacion_progress } }
            set_variable = { name = ca_pacificacion_progress value = 0 }
        }
    }

    option = {
        name = ca_costa_rica_events.4.a
        default_option = yes
        add_modifier = {
            name = ca_funding_separatists_modifier
            months = 6
        }
        # Con la frontera reforzada (evento 40.b) el dano es menor
        random_scope_state = {
            limit = { state_region = s:STATE_COSTA_RICA }
            if = {
                limit = { root = { has_variable = ca_cos_frontera_reforzada } }
                add_devastation = 5
            }
            else = {
                add_devastation = 10
            }
        }
        # La decision de Zepeda (ca_nicaragua_events.8) pesa en la invasion
        if = {
            limit = { has_global_variable = ca_nic_zepeda_apoyo_abierto }
            change_variable = { name = ca_pacificacion_progress add = -15 }
        }
        else_if = {
            limit = { has_global_variable = ca_nic_zepeda_expulsa }
            change_variable = { name = ca_pacificacion_progress add = 10 }
        }
        trigger_event = { id = ca_costa_rica_events.5 days = 1 }
    }
}

# Evento 5: El vacio de poder - Juan Rafael Munoz (29-30 de junio de 1836)
ca_costa_rica_events.5 = {
    type = country_event
    placement = root

    title = ca_costa_rica_events.5.t
    desc = ca_costa_rica_events.5.d
    flavor = ca_costa_rica_events.5.f

    icon = "gfx/interface/icons/event_icons/event_protest.dds"

    duration = 3

    trigger = {
        always = no # Solo desde el evento 4
    }

    # Historica: la expedicion restablece a las autoridades leales
    option = {
        name = ca_costa_rica_events.5.a
        default_option = yes
        if = {
            limit = { has_variable = ca_cos_expedicion_en_campo }
            add_treasury = -1000
        }
        else = {
            # La expedicion no habia salido (41.c): sale ahora, mas cara
            add_treasury = -5000
            set_variable = ca_cos_expedicion_en_campo
        }
        change_variable = { name = ca_pacificacion_progress add = 15 }
        ai_chance = { base = 80 }
    }

    # Tolerar a Munoz por ahora
    option = {
        name = ca_costa_rica_events.5.b
        set_variable = ca_cos_munoz_tolerado
        add_radicals = { value = 0.03 culture = cu:costa_rican }
        change_variable = { name = ca_pacificacion_progress add = 5 }
        # Guanacaste queda "pronunciada": Zepeda cumple su oferta de 500 hombres
        # (salvo que haya expulsado a Quijano o apoyado abiertamente desde el inicio)
        if = {
            limit = {
                NOR = {
                    has_global_variable = ca_nic_zepeda_expulsa
                    has_global_variable = ca_nic_zepeda_apoyo_abierto
                }
            }
            set_variable = ca_cos_pn_los_500_de_zepeda
            change_variable = { name = ca_pacificacion_progress add = -20 }
            c:NIC ?= { change_relations = { country = ROOT value = -20 } }
        }
        ai_chance = { base = 20 }
    }
}
